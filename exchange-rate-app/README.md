# Exchange Rate App

This project is a simple Node.js application that fetches and displays the current exchange rates for USD, EUR, and GBP.

## Features

- Fetches the latest exchange rates from a currency exchange service.
- Displays the exchange rates for USD, EUR, and GBP.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/exchange-rate-app.git
   ```

2. Navigate to the project directory:
   ```
   cd exchange-rate-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To run the application, use the following command:
```
node src/index.js
```

This will fetch the current exchange rates and display them in the console.

## Dependencies

- `axios`: A promise-based HTTP client for the browser and Node.js.
